# Общее описание расширения

Расширение **Indent Insight** предназначено для улучшения читаемости программного кода посредством цветовой подсветки уровней вложенности, а также для анализа структуры отступов и отображения статистики файла.

Расширение включает в себя следущие функции:

+ **Rainbow Mode** — подсветка отступов разными цветами в зависимости от уровня вложенности.
+ **Focus Mode** — выделение текущего уровня вложенности более ярким цветом. При перемещении курсора подсветка автоматически обновляется.
+ **Statistics** — сбор статистики открытого файла, включающей количество непустых строк, максимальную глубину вложенности и количество строк с глубокой вложенностью. Статистика реализована отдельной вкладкой в VS Code с помощью столбчатой и круговых диаграмм.

# Описание отдельных функций расширения

## Rainbow Mode

Подсветка отступов реализована с помощью функции **updateDecorations()**. Для определения уровня вложенности используется вспомогательная функция **getIndentLevel()**.

Алгоритм работы:

1. Получение текста открытого документа/файла - **editor.document**
2. Перебор всех строк
3. Подсчет первых пробелов строки - **text.match(/^ */)**
4. Вычисление глубины вложенности - **Math.floor(spaces / 4)**
5. Создание цветных диапазонов - **vscode.Range**


Цвета отступов выбираются из заранее заданного массива. После последнего цвета последовательность повторяется.

Для применения подсветки используется метод **setDecorations()** из **VS Code Extension API**. Он изменяет внешний вид отступов, не затрагивая содержимое файла.

## Focus Mode 

При перемещении курсора расширение определяет уровень вложенности строки, на которой находится пользователь, и изменяет интенсивность цветовой подсветки соответствующего уровня во всём документе.

Алгоритм работы:

1. Определяется номер строки, на которой находится курсор - **editor.selection.active.line**
2. Вычисляется уровень вложенности - **getIndentLevel()**
3. Перебераются все строки документа и сравниваются с активной по уровню вложенности.
4. Если уровень отступа совпадает с активным, для него выбирается яркая подсветка **focusDecorations**. Для остальных уровней используется обычная подсветка **normalDecorations**.
5. Выбранные варианты подсветки применяются к отступам - **editor.setDecorations()**

Для обычных отступов используется прозрачность 0.15, а для активного уровня — 0.65.

## Statistics

### Алгоритм сбора статистики

Для анализа отступов используется функция **analyzeDocument()**, которая последовательно обрабатывает строки открытого документа.

Алгоритм работы:

1. Создаются пременные для хранения количества строк, максимальной глубины вложенности и количества глубоких строк, а также массив для распределения по уровням.
2. Для каждой непустой строки вызывается функция **getIndentLevel()**, которая определяет уровень вложенности по количеству пробелов в начале строки.
3. Увеличивается общее количество непустых строк и счётчик строк соответствующего уровня вложенности.
4. Если найденный уровень больше текущего максимального значения, обновляется переменная **maxDepth**.
5. Если уровень вложенности превышает значение *DEEP_LEVEL*, увеличивается счётчик **deepLines**.

Полученные данные используются для отображения статистики файла и построения диаграмм.
Глубокими считаются строки уровень вложенности которых превышает 3.

### Визуалицаиця статистики

После анализа документа функция **createStatisticsHtml()** получает рассчитанные показатели и формирует HTML-страницу с графиками.

В окне статистики отображаются три основных показателя:

+ Общее количество непустых строк.

+ Максимальная глубина вложенности.

+ Количество строк с глубокой вложенностью.

Для наглядного распределения строк используются две диаграммы:

**Столбчатая** диаграмма показывает распределение строк по уровням вложенности. Для каждого уровня рассчитывается количество строк, после чего создаётся столбец соответствующей ширины.

**Круговая диаграмма** показывает соотношение обычных и глубоко вложенных строк. Процент глубоких строк вычисляется делением их количества на общее число непустых строк.

Окно статистики создаётся методом **vscode.window.createWebviewPanel()** и открывается в отдельной вкладке рядом с редактором.

При изменении содержимого анализируемого документа срабатывает событие **onDidChangeTextDocument()**, после чего функция **updateStatistics()** пересчитывает показатели и обновляет графики.
